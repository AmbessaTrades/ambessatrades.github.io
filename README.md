# AfriFluent

Speak African languages from your own life, starting with Kiswahili (Kenya).

- **Android:** [download the app](https://ambessatrades.github.io/get/) (the newest is always [AfriFluent.apk](https://ambessatrades.github.io/get/AfriFluent.apk), also in [Releases](https://github.com/AmbessaTrades/ambessatrades.github.io/releases), with what is new).
- **Any phone or computer:** https://ambessatrades.github.io/

This repo holds the built app only. The source is private.
